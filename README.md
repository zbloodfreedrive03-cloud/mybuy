# MyBuy (PWA)

แอปจดรายจ่ายแบบกล่องฟิสิกส์ ติดตั้งบน iPhone ได้เหมือนแอปทั่วไป

## ติดตั้งบน iOS
1. อัปโหลดทุกไฟล์ในโฟลเดอร์นี้ขึ้นเว็บที่เป็น HTTPS (Netlify Drop, Cloudflare Pages, GitHub Pages หรือ Vercel ใช้ฟรี)
2. เปิดลิงก์ด้วย Safari บน iPhone
3. กดปุ่มแชร์ แล้วเลือก "เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)
4. เปิดจากไอคอน MyBuy ได้เลย ใช้แบบเต็มจอและใช้ออฟไลน์ได้หลังเปิดครั้งแรก

## ฟีเจอร์
- ปุ่มกล้องซ้ายปุ่ม Add: เลือกถ่ายภาพหรือเลือกจากอัลบั้ม รูปจะแสดงเป็นลูกบอลในกล่อง กดที่ของแล้วกด "ดูรูป" เพื่อดูภาพใหญ่
- ปุ่มเขียวขวาปุ่ม Add: เพิ่มรายได้ (เงินเดือน ฟรีแลนซ์ ขี่รถ/ส่งของ ขายของ โบนัส ลงทุน ได้รับ อื่นๆ) ลบรายได้ได้จากรายการล่าสุดในหน้าเดียวกัน
- เงินคงเหลือ = เงินต้น + รายได้ทั้งหมด − รายจ่ายทั้งหมด
- มุมขวาบนสรุป -ใช้ไป (แดง) / +รายได้ (เขียว) ตามช่วงวัน/สัปดาห์/เดือนที่เลือก
- หน้าสรุปดูได้ทั้งรายวัน รายสัปดาห์ รายเดือน กราฟวงกลมหมุนเข้ามา และหมุนไปหาหมวดที่เลือก
- Export (CSV/JSON) รวมรายได้ด้วย รูปถ่ายไม่รวมในไฟล์ Export

## หมายเหตุ
- ข้อมูลเก็บในเครื่อง (localStorage) แยกกันระหว่าง Safari กับแอปที่ติดตั้ง ใช้ Export สำรองไว้ก่อนย้ายได้
- รูปถ่ายถูกย่อเก็บในเครื่องด้วย ถ้าพื้นที่เต็มแอปจะบันทึกรายการโดยไม่มีรูป
- ถ้าอัปเดตทับของเดิมแล้วยังเห็นหน้าเก่า ให้ปิดแอปแล้วเปิดใหม่ 1-2 ครั้ง
- ไฟล์: index.html, manifest.webmanifest, sw.js, icon-180/192/512.png
