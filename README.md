# MyBuy (PWA)

แอปจดรายจ่ายแบบกล่องฟิสิกส์ ติดตั้งบน iPhone ได้เหมือนแอปทั่วไป

## อัปเดตเวอร์ชันที่อัปขึ้น GitHub ไว้แล้ว
1. เข้า repo `mybuy` > Add file > Upload files
2. ลากไฟล์ `index.html` และ `sw.js` ใหม่ไปวางทับของเดิม แล้วกด Commit changes
3. รอ 1–2 นาที เปิดแอปจากหน้าจอโฮมแล้วปิดเปิดอีกครั้ง ข้อมูลเดิมในเครื่องจะยังอยู่ครบ

## ติดตั้งครั้งแรกบน iOS
1. อัปโหลดทุกไฟล์ในโฟลเดอร์นี้ขึ้นเว็บ HTTPS (GitHub Pages ใช้ฟรี)
2. เปิดลิงก์ด้วย Safari บน iPhone > ปุ่มแชร์ > เพิ่มไปยังหน้าจอโฮม

## หมายเหตุ
- ข้อมูลเก็บในเครื่อง (localStorage) แยกกันระหว่าง Safari กับแอปที่ติดตั้ง ใช้ Export สำรองไว้ก่อนย้าย
- ไฟล์: index.html, manifest.webmanifest, sw.js, icon-180/192/512.png
